## Available Endpoints

Every endpoint returns and object with 'results' key. Endpoints with pages has additional keys -> 'page', 'next', 'entries'

ALL query parameters are OPTIONAL

## Request and Response Format

- The title returns array of titles according to filters / sorting query parameters provided
- path: /titles/{id} - returns title acording to filters / sorting query parameters provided
